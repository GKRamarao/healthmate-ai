# HealthMate AI

An AI-powered personal health assistant built with:
- Google Cloud Run
- Gemini AI
- Firestore / Cloud Database

## Features
- Ask health-related questions and get AI answers
- Log daily health: symptoms, mood, medicine, sleep
- Stores health logs in cloud database
- Works from a web browser

## Tech Stack
- Frontend: React or HTML/JS
- Backend: Node.js / Python
- Deployment: Cloud Run
- AI: Gemini (Google AI)
- DB: Firestore / MongoDB
