# HealthMate AI

Overview
HealthMate AI is an AI-powered personal health assistant that helps users track health, log daily habits, and get instant answers to health-related questions. It uses cutting-edge generative AI (Gemini), Google Cloud Run for deployment, and Firestore as a secure cloud database.
This project aims to empower users to manage their health proactively with AI-driven recommendations and easy-to-use tools—all accessible right from their browser.

An AI-powered personal health assistant built with:
- Google Cloud Run
- Gemini AI
- Firestore / Cloud Database

## Features

- Ask health-related questions and get AI answers
- Log daily health: symptoms, mood, medicine, sleep
- Stores health logs in cloud database
- Works from a web browser

## Tech Stack
- Frontend: React or HTML/JS
- Backend: Node.js / Python
- Deployment: Cloud Run
- AI: Gemini (Google AI)
- DB: Firestore / MongoDB
